# Octomizer vanilla with HTML CSS JS PHP
This is the vanilla side project in HTML, CSS, JS, PHP of the Octomizer app: [https://octomizer.vercel.app/](https://octomizer.vercel.app/). The code for this main project is [here](https://github.com/hannahbesier/octomizer).

Currently in development to add the features of the main project but only using HTML, CSS, JS and PHP.

## Getting started:
Install php [here](https://www.php.net/downloads.php?os=windows)

Set system environmet variable for php `C:\php`

Check installation:
```
php --version
```

run in terminal:
```
php -S localhost:8000 router.php
```
open browser `localhost:8000`
